# Explorer++ 1.4.0 — GitHub Actions build (изолирано)

## Какво е това
Автоматична облачна компилация за тъмния ПРОТОТИП v0.1; не се инсталира Visual Studio на личния компютър.
GitHub Actions работи на стандартен windows-2022 runner с MSVC v142 + Windows SDK. Хранилището трябва да е PUBLIC, ако искаш стандартните Windows компилации без такса.

## Файлове
- `.github/workflows/build.yml` — инструкция за GitHub облачната машина
- `dark-v0.1.patch` — само 2-те променени UiTheming файлове

## Как протича
1. GitHub изтегля оригиналния код `derceg/explorerplusplus` от `version-1.4.0`.
2. Проверява и прилага малкия patch; ако не съвпада, компилацията спира.
3. Възстановява оригиналните NuGet зависимости и компилира Release x64 с v142.
4. При успешна компилация предоставя `ExplorerPP_1_4_Dark_TEST_ONLY.zip` в раздел Actions > run > Artifacts.
5. При неуспех: виж подробния лог в Actions или свали `build-diagnostics` и го изпрати в разговора.

## Статус
**Не е изпълнен GitHub build; резултатът и успешността на кода още не са потвърдени.**
Не заменяй стабилния Explorer++ и не използвай прототипа за важни файлови операции. Кодът използва експериментални/недокументирани Windows API; визуални проблеми са възможни.

## Лиценз
Оригинален Explorer++: GPL-3.0-only, от derceg/explorerplusplus; приложената модификация е само към това приложение.

## Публикуване
Създай PUBLIC GitHub хранилище със branch `main`. Добави съдържанието на пакета като файлове (не ZIP като един файл), така че пътят `.github/workflows/build.yml` да е запазен. Не качвай лични данни.
Дори без акаунт можеш да видиш документацията за GitHub Actions: https://docs.github.com/en/actions
